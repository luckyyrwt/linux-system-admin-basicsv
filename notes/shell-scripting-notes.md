# Shell Scripting Notes

## 1. Shell Script
A shell script is a file containing commands that run together to automate tasks.

## 2. Shebang
```bash
#!/bin/bash
Specifies that the script should run using Bash.

3. Comments
# This is a comment

Comments explain the code and are not executed.

4. Variables
name="Linux"
echo "$name"

Variables store values. Use $ to access a variable's value.

5. Command Substitution
TIMESTAMP=$(date "+%Y-%m-%d %H:%M:%S")

Runs a command and stores its output in a variable.
6. Disk Usage Command
df -h /
Displays human-readable disk usage for the root filesystem.

7. Pipe Operator
df -h / | awk 'NR==2 {print $5}'

Passes the output of one command to another command.

8. AWK
awk 'NR==2 {print $5}'
- NR represents the current record or line number.
- $5 represents the fifth field.
- print displays the selected field.

9. Parameter Expansion
usage=${disk_usage%\%}

Removes the trailing % character from a value such as 40%.

10. If-Else Condition
if [ "$usage" -ge 80 ]; then
    echo "Warning"
else
    echo "Normal"
fi


Runs different commands depending on whether the condition is true or false.
11. Numeric Comparison Operators
- -eq : Equal to
- -ne : Not equal to
- -gt : Greater than
- -ge : Greater than or equal to
- -lt : Less than
- -le : Less than or equal to

12. Grouping Commands
{
    echo "First line"
    echo "Second line"
}


Groups multiple commands so their combined output can be redirected or piped.

13. tee Command
echo "Hello" | tee output.txt

Displays output in the terminal and writes it to a file.

14. tee -a
echo "New entry" | tee -a output.txt

Displays output and appends it to a file without replacing existing content.

15. Log File
A log file stores output or events generated by a script for later review.

16. Relative File Path
LOG_FILE="bash-scripts/disk_usage.log"


A relative path is interpreted from the current working directory.

17. Disk Usage Monitor Project
The script:
- Checks root filesystem disk usage.
- Extracts the usage percentage.
- Removes the % sign for numeric comparison.
- Displays a warning when usage is 80% or higher.
- Displays a normal status when usage is below 80%.
- Prints a timestamped report in the terminal.
- Appends each report to a log file.
